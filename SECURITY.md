# Security Policy

## Reporting a vulnerability

Please report security issues through GitHub's **Report a vulnerability** feature in the repository's Security tab when it is available. This creates a private report.

If private vulnerability reporting is unavailable, contact the repository maintainer through a private channel listed on their GitHub profile. Do not include exploit details, credentials, personal data, or unpublished vulnerability information in a public issue.

## Scope

This repository contains documentation and workflow examples. Do not commit access tokens, passwords, customer data, production URLs, or screenshots containing private information. Use reserved example values such as `test@example.invalid`.
